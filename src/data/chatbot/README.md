# チャットボット知識ベース

このディレクトリには、チャットボットが使用する学習データをMarkdown形式で保存します。

## ファイル構成

- `01-company.md`: 会社情報
- `02-product.md`: 製品情報
- `03-construction.md`: 工事情報
- `04-faq.md`: よくある質問

## ファイルの書き方

### 基本構造

各MDファイルは、`#` で始まる見出しでセクションを区切ります。

```markdown
# セクションタイトル

セクションの内容をここに記述します。

## サブセクション

サブセクションの内容。
```

### カテゴリの自動判定

ファイル名に以下のキーワードが含まれていると、自動的にカテゴリが判定されます：

- `company` → 会社情報
- `product` → 製品情報
- `construction` → 工事情報
- `faq` → よくある質問

### キーワードの自動抽出

以下の技術用語や重要な単語は自動的にキーワードとして抽出されます：

- BESS、蓄電池、システム、コンテナ、出力、容量、仕様
- 安全性、安全対策、BMS、火災、リチウムイオン、監視
- EMS、エネルギー管理、電池管理、UI、運用
- 工事、建設、プロセス、期間、許認可、試運転
- 進捗、状況、運用中、工事中、計画中、プロジェクト
- 規模、MW、MWh、サイズ
- 電力系統、需給、用途、需給調整、容量市場
- 再生可能エネルギー、ピークシフト、周波数調整
- 導入、スケジュール、見積もり、商業運転
- 維持管理、メンテナンス、点検、サポート

## 新しいファイルの追加

1. ファイル名は `XX-category.md` の形式で作成（XXは番号）
2. ファイルを追加したら、開発サーバーを再起動してください
3. 知識ベースは自動的に読み込まれます

## 注意事項

- ファイルはサーバーサイドでのみ読み込まれます
- ビルド時に知識ベースが読み込まれます
- ファイルを変更した場合は、開発サーバーを再起動してください
